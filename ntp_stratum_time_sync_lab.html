Lab Progress Checklist & Step Explanations
  • 1
    [DC-01] Peer Server to Upstream 10.0.0.100
    Note: /manualpeerlist:"10.0.0.100,0x9" sets the upstream clock. Flag 0x9 enables SpecialInterval and NTP client mode. /syncfromflags:manual overrides AD hierarchy sync. /reliable:YES marks DC-01 as an authoritative time source for domain clients.
  • 2
    [DC-01] Restart w32time Service
    Note: net stop w32time && net start w32time restarts the Windows Time service, forcing Windows to load the updated registry parameters and manual peer list.
  • 3
    [DC-01] Force Resync on Server
    Note: w32tm /resync forces DC-01 to immediately synchronize its clock against 10.0.0.100, establishing DC-01 as a synchronized Stratum 2 server.
  • 4
    [Client] Peer Workstation to DC-01 (192.168.1.10)
    Note: Configures WORKSTATION-01 to use DC-01 (192.168.1.10). Flag 0x8 sends standard NTP client requests. Notice /reliable:YES is omitted because workstations do not serve time to other network hosts.
  • 5
    [Client] Restart w32time Service
    Note: Restarts the client's time service to apply the new peer setting pointing to DC-01.
  • 6
    [Client] Resync & Verify Stratum 3 Status
    Note: w32tm /resync forces WORKSTATION-01 to pull time from DC-01. Running w32tm /query /status verifies Stratum: 3 and confirms successful end-to-end network time synchronization!
