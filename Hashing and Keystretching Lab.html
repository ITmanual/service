Instructor-ready recap

What students should be able to explain

Credential flow, in plain language

1

The user creates a password

The password is a secret. A secure system treats it as temporary input, not as something to keep in readable form.

2

The system creates a random salt

The salt is unique per account. It prevents two people using the same password from ending up with the same stored verifier.

3

A slow KDF derives a verifier

PBKDF2 combines the password, salt, and iteration count. The deliberate work factor increases the cost of password guessing.

4

A later login repeats the derivation

The system retrieves the salt and settings, derives a verifier from the attempt, and accepts only an equal result.

// conceptual authentication logic
record = database.findByUsername(username)
candidate = PBKDF2(passwordAttempt, record.salt, record.iterations)

if timingSafeEqual(candidate, record.verifier):
    allowLogin()
else:
    denyLogin()

Key takeaways

  • A hash is a one-way output used for comparison, not a password someone can reverse.
  • A salt is not a secret. Its job is uniqueness, not hiding.
  • Key stretching makes every offline password guess more expensive for an attacker.
  • The database stores the username, salt, algorithm/work factor, and verifier—not the original password.
  • Good password storage is only one control: pair it with TLS, MFA, rate limiting, monitoring, and secure reset processes.
Why does a correct login match if the password is not saved?

Because the same password, salt, algorithm, and work factor create the same derived verifier. The login attempt is processed the same way as registration, then the two verifier values are compared.

What does salting protect against?

Unique salts stop shared password values from producing identical stored verifiers across accounts. They also make precomputed attack data far less reusable across a stolen database.

What does key stretching not replace?

It does not replace strong authentication design. Systems still need protections such as MFA, rate limiting, breach response, transport encryption, logging, and safe password recovery.
