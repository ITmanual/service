Scenario – Compact Virtualization Workstation
Design a build for an IT pro running multiple VMs with hardware encryption.
Your task is to choose a motherboard and CPU combination for a lab workstation. Requirements:

• They need a dedicated GPU plus a capture card for recording training sessions.
• The OS and VMs should run from an NVMe SSD for best performance.

Scenario – Secure Virtualization Host
Configure BIOS/UEFI for VMs and hardware-based encryption.
The system you just built will run multiple virtual machines and must support hardware-based disk encryption for sensitive data.

Requirements:
• Hypervisor (Type 1 or Type 2) must be able to use CPU virtualization extensions.
• Windows will use BitLocker with a hardware root of trust.
• Only trusted operating systems should be allowed to boot.
• Unauthorized users must not be able to change BIOS/UEFI settings.

Case T1 – Continuous Beeps, Blank Screen
New build, no display, system never reaches POST screen.
Symptom Summary
• System powers on, fans spin.
• No video output at all.
• Continuous, repeating beeps from the motherboard speaker.
• You have verified the monitor and cable on another system.
Most Likely Component/Area
Think about common POST beep code meanings from your study materials.
Best First Action
If the system never reaches POST, the OS and storage haven’t loaded yet.
